# AI usage policy

OpenShao uses and accepts AI assistance. The person submitting a contribution is
responsible for understanding, reviewing and testing it.

## Assistance and responsibility

AI can help with research, code, debugging, tests and documentation.
The contributor remains responsible for the work. Submit only work you understand and can
explain in review: what it changes, why, and how you checked it.

- Disclose the tools used and which parts of the submission they helped produce.
  Include this in the issue or PR description.
- Read the complete diff. Check generated suggestions against the source and the
  relevant game behavior before submitting them.
- Run the relevant checks. Report the results accurately.
  State which parts you did not test or remain uncertain about.
  Never invent test results, sources or compatibility claims.
- Review generated text before submission. Edit it for accuracy and clarity.
  Keep issues, PRs, comments and documentation
  concise, factual and in your own words.

Maintainer review does not replace the contributor's own investigation and testing.
The maintainer will reject unreviewed output and speculative fixes.
The maintainer will also reject bulk changes the author cannot explain.
Repeated disregard for these rules can lead to a contribution ban.

## Preserve the game

The [project direction](CONTRIBUTING.md#project-direction) applies to AI-assisted work.
Fixes, improvements and restorations must respect Shaolin Monks' identity.

An AI suggestion is not evidence of the original developers' intent.
Support each restoration with findings from the game or reliable development material.
Identify any interpretation. Do not present generated dialogue, voices, artwork or
story material as recovered content.

You can offer AI-created content absent from the original game as an optional
[mod](CONTRIBUTING.md#creative-additions-and-mods). Label it as a new creation or interpretation.
Keep it separate from restorations in the base game. Use the current mod system's capabilities.
The same review, disclosure and licensing rules apply.

## Public submissions

Follow the [game-file and private-data rules](CONTRIBUTING.md#game-files-and-private-data).
Check the entire submission, including attachments and commit history, yourself.
Uploading prohibited material results in a permanent ban, including accidental uploads.
